AI transcript analysis

When a video has no SponsorBlock data, the extension reads its chapters and transcript to find ads. Without an API key it uses keyword matching, which only catches obvious ad reads. With a key, a language model reads the transcript and works in any language. Results are cached per video, so each video is analyzed once.

Transcripts of videos you watch are sent to the provider you choose.

Cache

Clear saved analysis results so videos get re-analyzed, for example after changing models.
